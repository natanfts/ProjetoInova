# Pasta de Assets

Esta pasta contém os arquivos estáticos da aplicação, como imagens e logos.

## Logo

Coloque o arquivo da logo aqui com o nome `logo.png`.

A logo será exibida automaticamente no header do painel do enfermeiro quando o arquivo estiver presente.

### Especificações recomendadas:
- **Formato**: PNG (com fundo transparente preferencialmente)
- **Altura**: ~60px (será redimensionada automaticamente)
- **Nome do arquivo**: `logo.png`
